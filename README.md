# Holien Secrets Manager（Holisec）

個人使用的單機桌面應用程式，管理帳密與伺服器金鑰。在自己的電腦上執行，沒有伺服器端，將帳號密碼、API Token，以及伺服器使用的 SSH / TLS 私鑰與公鑰加密後存放在個人 Google Drive 的自訂資料夾（資料夾與檔案名稱皆可自訂，有預設值），支援多裝置同步、金鑰輪替、主機綁定、自訂資料夾整理、選擇性匯出、區網點對點傳送給另一位使用者，以及從 Chrome 匯入已儲存的網址與帳密。

**三個不變條件**

1. 資料永遠在上傳前於本機加密，Google Drive 上只有密文。
2. 主密碼與由其推導的金鑰永不離開本機。
3. 沒有任何第三方伺服器，工具只與 Google Drive API 溝通。
